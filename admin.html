Menü Yönetimi

Değişiklikler doğrudan GitHub deposuna kaydedilir ve menüde 1-2 dakika içinde görünür.

Token nasıl alınır?
  1. GitHub → Fine-grained token sayfasını açın.
  2. Repository access: Only select repositories, menü reposunu seçin.
  3. Permissions → Contents: Read and write.
  4. Oluşturulan anahtarı kopyalayıp buraya yapıştırın. Anahtarı kimseyle paylaşmayın.
